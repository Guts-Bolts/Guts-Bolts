# Studio Workflow

Use this skill when the user asks to create, inspect, or modify a Guts & Bolts Studio project.

1. Inspect the current scene and relevant objects before changing anything. Use the real object IDs returned by Studio tools.
2. Check the engine documentation when an API, class, property, or workflow is unfamiliar. Never assume Roblox APIs are identical to Guts & Bolts.
3. Break multi-step edits into small operations. Prefer editing existing objects over recreating them.
4. After each meaningful change, inspect the resulting state with Studio tools.
5. Use the native AI Activity and undo workflow. Explain which changes were made and report any failed operations.
6. Do not claim a scene, script, asset, or playtest was changed unless the corresponding tool confirms it.

Studio is one part of Guts & Bolts. If the request concerns accounts, friends, inventory, marketplace, or live game sessions, use those capabilities only when real authorized tools are available.
